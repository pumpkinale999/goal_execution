## 1. 问题与动机

### 1.1 现网缺口

| 层 | 行为 | 后果 |
| -- | ---- | ---- |
| **战略树 API** | `GET /ge/objectives` 已认证即 **全量骨架**（鉴权共识 §5.1） | 登录用户看见与己无关的专项名 |
| **专项列表 API** | `GET /ge/programs` **全量**返回（`routes_ge.py`） | 旁路泄漏专项名 |
| **专项详情 API** | `GET /ge/programs/{id}` 知 id 即 200 + 元数据（`projects[]` 虽过滤） | 旁路泄漏专项名 |
| **Board API** | `GET /objectives/{id}/board-projects` 返回 objective 下 **全部 program 名** | 旁路泄漏专项名 |
| **项目读 API** | `filter_projects_for_user` / `can_read_project` 已按角色收窄 | **树与项目几何分裂** |
| **FE「所参与」** | 仅藏 `参与=0` 专项；可关；localStorage | **非安全边界**；误伤 governor 全貌 |
| **draft 创建者** | `created_by` 进读权；且实现未严格绑 `status=draft` | 与「建项=管理权」不一致 |
| **角标** | `(可见, 参与)` 在满树上易被误解为全员可见度 | 信息噪声 |

### 1.2 产品原则

> **左树是个人投影，不是公司目录。**  
> 治理者在负责节点看全貌；参与者只看自己的项目与祖先链；创建跟着管理权走，不跟着「我点过创建」走。

## 3. 规范要求（Normative）

### 3.1 投影几何

```text
personal_tree(user) =
  ⋃_{g ∈ governed_anchors(user)}  (ancestors(g) ∪ subtree(g))    # 含空 program（C20）
  ∪
  ⋃_{p ∈ execution_anchor_projects(user)}  (ancestors(program(p)) ∪ {p})

governed_anchors =
  Objective/Program 节点使 is_goal_subtree_governor(user, node)

execution_anchor_projects =
  { project | user 为 PM ∨ roster 成员 ∨ task assignee }
  （目标态：不含 created_by；与 can_read 的「参与路径」一致）

reviewer → 全树（不受 personal_tree 限制）
```

| 角色 | 左树 | 建项 | 读项目 |
| ---- | ---- | ---- | ---- |
| 子树 governor | 负责子树全貌（**含空专项**）+ 它处仅祖先 | ✓ | 子树内全量 |
| PM（非 governor） | 本项目 + 祖先 | ✗ | 本项目 |
| roster / assignee | 参与项目 + 祖先 | ✗ | 参与项目 |
| 无关同事 | **空** | ✗ | ✗ |
| 评审员 | 全树 | ✓ | 全量 |

**项目子节点加载**：保持现网 FE **懒加载**（`list_projects?program_ids=`）；`list_objectives` 投影 **program 层**即可，不要求 API 内嵌 project 子树。

### 3.2 读权公式（目标态 · 废止 draft 创建者）

```text
can_read_project(user, project) =
  is_project_pm(user, project)
  ∨ is_participant(user, project)          # ge_access：PM ∪ roster ∪ assignee
  ∨ is_goal_subtree_governor(user, project)
  ∨ is_reviewer(user)
```

- **`created_by_user_id`**：写入审计字段；**禁止**进入上式。
- **失权后 draft/空壳**：由当前 `is_goal_subtree_governor` 或评审员 force delete 处置；原创建者若无上式身份 → 不可读。

### 3.3 API 行为

#### 3.3.1 HTTP 拒绝语义（钉死 · 对齐现网）

| 实体 | 不存在 / 软删 / **投影外** | detail |
| ---- | --------------------------- | ------ |
| **Project** | 404 | `project_not_found`（现网已有） |
| **Program** | 404 | **`not_found`**（现网 `GET /programs/{id}` 已用；**禁止**新造 `program_not_found`） |
| **Objective** | 404 | **`not_found`**（与 board 等现网一致） |

包络：`{"detail": "<上表>"}`。投影外 **禁止** 200 空壳或仅藏 `projects[]` 仍返 program 元数据。

#### 3.3.2 P0 同窗接口表（Normative）

| API | 现网缺口 | 目标态 |
| --- | -------- | ------ |
| `GET /ge/objectives` | 全量骨架 | **个人投影**；评审员全量 |
| `GET /ge/objectives/{id}` | （若存在）全量子节点 | ∉ 投影 → **404 `not_found`**；`programs[]` 仅投影内 |
| `GET /ge/programs` | **全量专项列表** | 仅返回 **personal_tree 内 program**（评审员全量） |
| `GET /ge/programs/{id}` | 知 id 即见元数据 | ∉ 投影 → **404 `not_found`**；`projects[]` 仍 `filter_projects_for_user` |
| `GET /ge/projects` | 已 `filter_projects_for_user` | 去 `created_by`；无 filter 时返回 actor 可读全集（≈ 投影项目并集，**不宽于** C15） |
| `GET /ge/objectives/{id}/board-projects` | **program 名全量** | objective ∉ 投影 → **404**；`programs[]` **仅投影内**；`projects[]` 仍过滤 |
| `GET /ge/programs/{id}/people-summary` | governor 门禁 | **不变**；须 objective/program 已在投影内才可 200 |
| `GET /ge/me/pa-project-roles` · PA scope | 依赖 `filter_projects_for_user` | 去 created_by；≡ Web |
| 建项向导数据源 | `list_objectives` | **个人投影 ∩ `can_create_project`** |

**禁止**：面向普通 JWT 的 `projection=full`。运维/脚本全量 → **评审员 service** 或既有 break-glass。

#### 3.3.3 Portfolio（本迭代 OUT · 不变量）

`/ge/portfolios/*` 走 **组织鉴权**（部门/团队/人员 portfolio），**不**按个人左树裁剪。

不变量：portfolio 中出现的 **项目名** 仍须 ⊆ `can_read_project`（不得宽于项目读权）；本迭代 **不** 改 portfolio 路由实现，仅回归确认无回归放宽。

### 3.4 祖先与角标

| 规则 | 说明 |
| ---- | ---- |
| 祖先节点 | 仅骨架；**不**嵌套投影外项目名 |
| 角标注入 | **仅**投影结果中保留的 program |
| 不变量 | `0 ≤ 参与 ≤ 可见`（口径同角标文档 C2–C7；**废止**所参与过滤条款） |

#### 3.4.1 左树锚点 vs 角标「参与」（双口径 · 不合并）

| 概念 | 口径 | 模块 |
| ---- | ---- | ---- |
| **左树 / 执行锚点**（规则 B） | PM ∪ **roster** ∪ **assignee** | `ge_access.is_participant` · `filter_projects_for_user` |
| **角标「参与」** | PM ∪ **roster** only（**不含**仅 assignee） | `ge_related_project_counts.my_related_project_count` |

**预期**：仅 assignee、非名单非 PM → 左树 **有** 该项目 + 祖先；角标 **`(可见≥1, 参与=0)`** — 与《左树角标》C5/C6 一致，**本迭代不改角标公式**。

**角标「可见」**：`filter_projects_for_user` ∩ 生命周期排除集（含 assignee 可读项）。

### 3.5 FE

| 项 | 要求 |
| -- | ---- |
| 「所参与」勾选 | **删除**（含 localStorage 键 `onlyParticipated` 迁移/忽略） |
| `filterGoalsTreeByParticipation` | **删除**及所有调用 |
| `ExecutionLayout` / `ExecutionGoalsTree` props | 移除 `onlyParticipated` 受控/非受控分支 |
| 空树文案 | 「暂无与您相关的目标或项目」；**无**「查看全公司」 |
| 显示归档 | 保留；**叠在投影之上**；归档节点不得宽于个人投影 |
| 年组/季度过滤 | 保留；叠在投影之上 |

### 3.6 Actor / PA / Service

| 通道 | 规则 |
| ---- | ---- |
| 投影主语 | **effective user**（JWT / Act-As / PA `actor_user_id`） |
| 非评审员 service | ≡ 对应 actor 的个人投影 |
| 评审员 service | 全量 |
| PA | `pa_goal_scope` ≡ Web；**去掉** draft 创建者例外（GO-21 / I10 反转） |

### 3.7 性能

`list_objectives` 及投影相关路径：

- **须**复用 / 扩展 `_governed_program_ids_for_user` 类批处理；

- 测试：**T13** PERF 间谍（对齐 GE-PERF / `test_ge_perf_projects` 风格）。

## 附录 C · 投影算法（实现参考 · Normative 步骤）

输入：`user`（非评审员）。输出：保留的 `objective_id` / `program_id` 集合（及树形结构）。

1. **批处理治理集**  
   `governed_obj_ids` ← 仅 **objective** owner/pmbp 及其向下子树（**不得**因专项 ownership 抬升父 objective）；  
   `governed_prog_ids` ← `_governed_program_ids_for_user`（自有专项 ∪ 目标治理子树下专项）。  
   （**禁止** per-node `is_goal_subtree_governor`）。

2. **执行锚点项目集**  
   `anchor_project_ids` ← PM ∪ roster ∪ assignee 的项目 id（**不含** created_by；**不含**仅 governor 读、非参与的项目）。

3. **祖先闭包（骨架）**  
   对每个 `governed_prog` / `anchor_project`，沿 `program → objective → parent` 标记祖先节点为 **skeleton**（仅骨架，**不**对父 objective 做全貌展开）。

4. **治理子树并集**  
   对每个 **objective** `governed` 锚点，标记其 **整棵子树**（含 **0 项目 program** · C20）为 **full**。专项 governor 锚点止于该 program（T3/T3b）。

5. **剪枝建树**  
   从年组根向下：仅保留被标记节点；兄弟未标记分支删除；无关年组根不出现（C7）。

6. **角标与懒加载**  
   对保留的 program 注入 `(可见, 参与)`；项目子节点仍由 FE `GET /projects?program_ids=` 懒加载（已 `filter_projects_for_user`）。

评审员：跳过 1–5，返回全树。
