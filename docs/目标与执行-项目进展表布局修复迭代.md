## PROG-MS2 · 呈现层（CSS + 组件）

### DOM 结构（与线框一致）

```text
<table>
  <tr>
    <td rowSpan={n} class="execution-project-progress-phase">阶段名</td>
    <td class="execution-project-progress-task">
      <div class="execution-project-progress-task-inner">
        <span>任务标题</span>
        <span class="badge">…</span>
      </div>
    </td>
    <td class="execution-project-progress-outcome">…</td>
  </tr>
  <!-- 同阶段后续行：无 phase td -->
</table>
```

### CSS 变更

| 项 | 变更 |
| -- | ---- |
| `.execution-project-progress-phase` | `min-width: 5.5rem`；`vertical-align: middle` |
| `.execution-project-progress-task` | 移除 `display:flex`；`vertical-align: top` |
| `.execution-project-progress-task-inner` | **新增** `display:flex; flex-wrap; gap` |
| `.execution-project-progress-outcome` | 保留 `word-break: break-word` |
| 孤儿规则 | 删除 `execution.css` 原 3503–3506 无选择器块 |

### 组件
