## 1. 问题与动机

Sub/Program 已有 `period_*`，左树仅按年组浏览，缺少「这一年看哪一季」的镜头。用 **年组旁 filter** 表达节奏，**不加深树**；邻年各自默认，避免全局「本季」掏空归档/规划年。

## 3. 规范要求（Normative）

### 3.1 放置与交互

| 项 | 规则 |
| ---- | ---- |
| **位置** | 年组行右侧（「2026」旁） |
| **控件** | 紧凑触发器 `({Qn\|全年} ▾)` + 弹出菜单；触发点击 **须 stopPropagation**，避免误触年组导航（M39） |
| **testid** | `execution-tree-year-period-filter-{year}` · 选项 `…-option-all` · `…-option-Q{n}` |
| **点年组头** | 仍 `navigate(/execution/years/{YYYY})`；展开/折叠不变 |

**线框**：

```text
☐ 全部                         + 新建年度战略

▾ 2027(全年 ▾)
   └─ 快速增长 …

▾ 2026(Q3-当季▾)
   └─ 公众公司
       ├─ （与 Q3 相交的子目标）
       └─ …
```

年组头旁为 **紧凑触发器**（紧贴年份、无空隙）`({Qn|全年|Qn-当季} ▾)`：点三角/括号打开菜单；点年份本身仍进年组管理面。当前公历年当前季文案为 **`Qn-当季`**（非「本季度」）。

### 3.2 选项与存盘（P0）

| 文案 | 存盘值 | 出现条件 |
| ---- | ------ | -------- |
| 全年 | `all` | 每年都有 |
| Q1 | `{year}-Q1` | 每年都有 |
| Q2 | `{year}-Q2` | 每年都有 |
| Q3 | `{year}-Q3` | 每年都有 |
| Q4 | `{year}-Q4` | 每年都有 |

- **`Qn-当季`**：仅当 `today` 的公历年 == 该 `planning_year`，且该选项为 `today` 所在日历季时，**用此文案替代 `Qn`**（例：触发器/菜单均为 `Q3-当季`）。  
- **禁止** 独立选项「本季度」/「当季」/ 存盘 `current_quarter`。  
- **钉死语义**：用户选中的是具体 `YYYY-Qn`；日历进入下一季后，标注挪到新 Q，**选中值不变**（不自动跟随）。  
- **禁止** 跨年选项（2026 组内不得出现 2025-Q3）。  
- **P0 不做** 月份、自定义起止。

**窗口（日历、闭区间、date-only、无 TZ 换算）**：

| 值 | 窗口 |
| --- | ---- |
| `all` | 不裁剪 |
| `{Y}-Q1` | `Y-01-01` … `Y-03-31` |
| `{Y}-Q2` | `Y-04-01` … `Y-06-30` |
| `{Y}-Q3` | `Y-07-01` … `Y-09-30` |
| `{Y}-Q4` | `Y-10-01` … `Y-12-31` |

**默认（无 LS / LS 损坏时）**：

| 年组 | 默认 |
| ---- | ---- |
| `planning_year == 今天的公历年` | 今天所在 `Qn`（`{year}-Qn`） |
| 其它年 | `all` |

### 3.3 命中与投影（读模型 · 前端）

前置（**M40-0**）：确认 `GET /objectives`（经 BFF）树节点 Sub/Program **实填** period 字段。FE 类型已含 `period_*` / `resolved_period_*`。若响应缺 → 先补只读字段再上 UI。缺有效窗的节点：**仅 `all` 可见** + dev 日志；**禁止** 逐节点打详情。

**有效窗（C14）**：

```text
start = resolved_period_start ?? period_start
end   = resolved_period_end   ?? period_end
若 start 或 end 缺省 → 无有效窗（仅 all 可见）
```

对年组 `Y`、filter ≠ `all`、窗口 `W`：

1. **相交**：`start <= W.end && end >= W.start`（闭区间、`YYYY-MM-DD` 字典序可比）。
2. **Sub / Program** 相交则保留；仅 Program 命中 → 保留 Program + 祖先路径。
3. **Project** 随可见 Program。
4. **Company 根** 无可见子孙 → **不渲染**。
5. **granularity=year**（若有）：整年有效窗 → 各 Q 下可见（C13）。

**不改** GE 写 API；**禁止** P0 新增服务端筛接口。

### 3.4 选中态与深链

| 场景 | 行为 |
| ---- | ---- |
| 用户改年 `Y` 的 filter，当前选中 ∉ 过滤结果 | **清选中** · `navigate(/execution/years/Y)` · 该年组头旁 **inline** 提示（testid `execution-tree-year-period-hint-{Y}`，文案见 C11） |
| 深链目标 ∉ 该年当前 filter | 取节点有效 `start` → 落入的 `Qn` → 设 filter=`{Y}-Qn`；无 start → `all`；写 LS → 选中（C12） |
| 过滤未藏掉选中 | 保持选中 |

**C12 选季例**：Sub `2026-06-01..2026-08-31`、当前 filter=`2026-Q1`、深链进入该 Sub → 设为 `2026-Q2`（start 在 Q2），**不是** Q3、也不是最大重叠算法。

### 3.5 与「全部」、年组管理面

| 项 | 规则 |
| ---- | ---- |
| **全部** | 只控 lifecycle；不入 period LS |
| **组合** | lifecycle ∩ period |
| **年组管理面** | **不受** 左树 period 约束（本迭代） |

### 3.6 持久化（localStorage）

| 项 | 规则 |
| ---- | ---- |
| **Key** | `execution.tree.periodFilter.v1:{effectiveUserId}` |
| **Value** | `{ "<planningYear>": "all" \| "<year>-Q<n>", ... }` |
| **主体** | effective 用户（Act-As 隔离） |
| **写入** | 仅用户改下拉 / C12 深链调整时；禁止无变更渲染写 |
| **清除** | logout 不强制清；坏 JSON → 默认 |
| **非法值** | 忽略该年条目 → 默认 |

### 3.7 URL

**P0：不实现** `?period=`。个人镜头仅 LS + 默认。

### 3.8 无障碍与文案

- 下拉 `aria-label`：`{year} 时间窗口`
- 空年组：`本窗口暂无子目标`
- C11 提示：树旁 inline（非全局浮层）；`role="status"` 可
- 行内 Q 徽章：P0 不做
