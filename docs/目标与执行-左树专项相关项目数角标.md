## 0. 共识（已锁 · v0.4）

| # | 共识 |
| - | ---- |
| C1 | 左树专项标题显示 `名称(可见, 参与)`，**含 `(0, 0)`**（如 governor 空专项） |
| C2 | **参与** = 该专项下，当前用户为 **PM 或项目成员（roster）** 的有效项目数 |
| C3 | **可见** = 该专项下，当前 Actor **ACL 可读**（`filter_projects_for_user`）的有效项目数 |
| C4 | **有效** = 排除 `cancelled` / `archived` / soft-deleted；可见与参与 **同一排除集** |
| C5 | **参与不算**：仅任务 assignee、仅 `created_by`（assignee 仍可计入**可见**；created_by **不再**计入可见 · GE-VIS-1） |
| C6 | 评审员 / governor：**可见**可为专项下有效项目全集；**参与**仍按 C2（可 `可见 ≫ 参与`） |
| C7 | 不变量：`0 ≤ 参与 ≤ 可见` |
| C8 | 字段：`my_visible_project_count` + `my_related_project_count`；**保证出现**于投影内 `GET /ge/objectives` program 与 `GET /programs/{id}` |
| C9 | tip / title：`可见 n · 参与 m` |
| C10 | ~~「所参与」勾选~~ **废止**（GE-VIS-1）：投影已按角色给出正确集合；标题行仅保留「全部」等 |
| C11 | ~~默认勾选所参与过滤~~ **废止** |
| C12 | 「全部」(归档) **localStorage** 按 `effectiveUserId` 记忆（不再记忆所参与） |
| C13 | **徽章 ≠ 列表**：`projects[]` 按 `can_read`；双计数是**徽章口径** |
