## 1. 需求与用户故事

### 1.1 背景

Master / Agent Builder / Personal Assistant 是平台**内置独立 Agent**（各轨自有 profile 与能力边界），侧栏灰点、Gateway/readiness 等问题需要统一运维入口，与业务 slug 分离。

**数坤坤（personal-assistant）**：独立第三轨，**可适度配置 Tool/Skill**（白名单，默认 kbase）辅助用户个人场景；**不是** Master 派生副本，也**不是**「零能力纯聊天」。

### 1.2 纳入 / 不纳入

| 纳入 | 不纳入（首版） |
| --- | --- |
| 三 profile 诊断、Gateway 启停、Profile/Tools/Skills/Model 只读 | Git `@ver`、Lab/Production Radio、promote/demote |
| BFF 合并 WSS 连接态 | skills.lock 写、Tool overlay PATCH |
| P1：`logs` 端点 | intel/coder/office、master profile 在线编辑 |

### 1.3 用户故事

| ID | 作为 | 我要 | 以便 |
| --- | --- | --- | --- |
| **SA-1** | 审批人 | 在管理中心 **数坤坤** Tab 查看 Assistant 概览（Gateway + WSS + readiness） | 灰点时可一键 restart 并确认变绿 |
| **SA-2** | 审批人 | 在 **Master** / **Builder** 独立 Tab 运维 | 平台 Gateway 统一运维 |
| **SA-3** | 审批人 | 只读浏览 live profile 的 Tools / Profile / Skills / Model | 不必 SSH 或误走 slug API |

#### 1.4.2 三轨子页矩阵

| 子页 | Master | Builder | Assistant |
| --- | --- | --- | --- |
| **概览** | Gateway + WSS + **编排就绪**（Kanban 正向）+ Doctor（lazy） | Gateway + WSS + **Lab 就绪** + git/plugin 高亮 | Gateway + WSS + **Personal 模板** + runbook |
| **Tools** | live runtime（**含 kanban**）；链 Tool 中心 | live runtime（**lab_***）；无 kanban workflow 说明 | **白名单** Tool（默认 `kbase`）；审批人 PATCH；运行时诊断 |
| **Skills** | `skills/` 只读（编排/MCP supply） | 教练 skill 只读 | **助手专用** skill 只读 + **forbidden** 编排 skill 诊断 |
| **Model** | live model + Model 中心（**secrets/model 真源**） | live + Model 中心（继承 master） | live + composer 用户模型说明 |
| **Profile** | live 树；**无 sync**；链 Tool/Model 中心 | live 树 + **从 master 同步** | live 树；**独立 profile**（只读，无 sync/重置 UI） |
| **Logs** | gateway.log tail | —（P2 可选） | gateway.log tail |

Assistant 子 Tab 顺序：`overview → profile → model → tools → skills`（诊断放后）。

#### 1.4.3 readiness 检查项矩阵

| 检查 id / 语义 | Master | Builder | Assistant |
| --- | --- | --- | --- |

| `config.kanban_toolset`（Kanban 正向） | **必须通过** | 忽略 | **必须失败若启用** |
| `config.d50_dispatch` / `config.d50_no_kanban_toolset`（Lab D50） | **忽略** | 必须通过 | 必须通过 |
| `config.skstudio_agent_lab_plugin` + `env.agent_lab_git` | 忽略 | 必须通过 | 忽略 |
| `config.allowed_toolsets` + `config.no_lab_plugin` + forbidden skills | 忽略 | 部分 | **必须通过**（白名单内可选，如 kbase） |
| `readiness_kind` | `master` | `builder` | `assistant` |

#### 1.4.5 Runbook 分流

- **Assistant 灰点（SA-1）**：数坤坤 Tab 概览 → WSS → restart → 查 `.env` 连通与 inference key

- **Builder 教练**：Builder Tab → Lab 就绪 → Profile **从 master 同步** → `hermes -p agent-builder doctor`

## 2. 架构与 API

### 2.1 对象映射

| UI id | profile_id | gateway_role | WSS 检查（skstudio） |
| --- | --- | --- | --- |
| `master` | `master` | `master` | `is_master_gateway_registered()` |
| `builder` | `agent-builder` | `agent_lab` | `is_builder_gateway_registered()` |
| `assistant` | `personal-assistant` | `personal` | `is_personal_gateway_registered()` |

**WSS 真值在 skstudio** `connection_registry`；Hermes API 不可见 WSS，BFF `summary` 必须合并 `wss_connected`。

### 2.2 Hermes REST

前缀：`/integrations/skstudio/v1/admin/center/system-agents`（Dashboard 挂载：`/api/plugins/skstudio-dashboard/...`；≤14d 兼容旧 `/api/plugins/kanban/...`）

| Method | Path | 说明 |
| --- | --- | --- |
| GET | `/system-agents` | 三行元数据 |
| GET | `/{id}/summary` | gateway + `readiness_kind` + runtime_readiness + `model` + doctor（`?include_doctor=0` 默认跳过） |
| PATCH | `/{id}/config/toolsets` | **assistant only** · 审批人 · 白名单 toolset（当前 `kbase`） |
| GET | `/{id}/runtime/tools?platform=skstudio` | live profile tools |
| GET | `/{id}/profile/inspect` | 无 git_version_dir / drift |
| GET | `/{id}/profile/files?path=` | 脱敏读文件 |
| POST | `/{id}/gateway/{start\|stop\|restart}` | `gateway_*_profile(profile_name)` |
| POST | `/{id}/profile/sync-runtime` | **builder only** 镜像 master；master / assistant → 400 |
| GET | `/{id}/logs?tail=50` | `profiles/{id}/logs/gateway.log` |

模块：`hermes-agent/plugins/skstudio-dashboard/dashboard/system_agent_runtime.py`、`skstudio_system_agents_api.py`（R4）。

### 2.3 skstudio BFF

前缀：`/api/v1/admin/center/system-agents/*`  
鉴权：`require_admin`（审批人）  
`GET .../summary` 响应含 `wss_connected`（合并 registry）。

Gateway restart 代理 Hermes 503 → BFF **502**。

### 2.4 前端路由

| 路径 | 页面 |
| --- | --- |
| `/admin/center` | 重定向至 **Assistant** 概览（或末次 Tab） |
| `/admin/center/master` | Master 概览 |
| `/admin/center/master/{tools,skills,model,profile,logs}` | Master 子页 |
| `/admin/center/builder` | Builder 概览 |
| `/admin/center/builder/{tools,skills,model,profile}` | Builder 子页 |
| `/admin/center/assistant` | Assistant 概览 |
| `/admin/center/assistant/{profile,model,tools,skills}` | Assistant 子页 |
| `/admin/center/system/*` | 重定向至上表（兼容） |

testid：`admin-center-tab-master` / `-builder` / `-assistant`；`admin-center-{track}-subnav`；`admin-center-{track}-summary`。

### 2.5 与 slug 中心差异

| 项 | slug 中心 | 系统智能体 |
| --- | --- | --- |
| 标识 | 业务 `slug` | `master` / `agent-builder` / `personal-assistant` |
| profile 目录 | `lab-<slug>` 或 Git @ver | `profiles/{profile_id}/` 直读 |
| Gateway API | `gateway_profile_name(slug)` → 可能 `lab-*` | `gateway_*_profile(profile_id)` |
| WSS |  per-thread 或 slug-keyed | master / builder / personal singleton |

**禁止** UI 调 `/agent-lab/agents/master/...`（会把 master 映射成 `lab-master`）。

### 3.3 Runbook（Assistant 灰点）

1. 概览页确认 Gateway 进程与 WSS 状态  
2. readiness 未通过 → 查 live profile `config.yaml` / `.env`（**独立 profile**，不从 master 派生）  
3. 配置就绪但 WSS 红 → **重启** Gateway；仍失败则查 `SKSTUDIO_HERMES_WS_URL` / `HERMES_ADAPTER_SERVICE_TOKEN`  
4. CLI：`sudo systemctl restart hermes-gateway-personal-assistant`
