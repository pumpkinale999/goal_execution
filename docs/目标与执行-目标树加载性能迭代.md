## 1. 问题演进

### Phase 1（GE-PERF）

打开执行力时并行：`objectives`（sibling N+1 + 全表 lifecycle）、全量 `projects`×逐条 ACL、`me/queues` 挡体感。另有 MeOrg portfolio 用户级 N+1、PA 同吃 `list_objectives`。

### Phase 2（GE-PERF2）

Phase1 后仍钝：角标仍拉完整 `me/queues`；首屏仍拉全部可见 projects。改为轻量 count + 按展开 program 懒加载。

### Phase 3（GE-PERF3 · 现网 v26.11.28）

Phase2 后首页仍慢的主因：

1. **sessionStorage 陈旧 `program:`**：历史点专项曾误写入展开集；v26.11.27 起新点击不再写入，但**旧键仍在** → 进 `/execution` 仍发膨胀 `program_ids` batch。
2. **GE 单 worker + 画布 `me/queues` 每 30s**：与首页 `objectives` / count / batch 争用。
3. **AppShell 扇出**（sidebar×2、审批队列、偶发 messages）：进模块带宽争用（跨壳层，本文 P2/OOS）。

## 2. 现网行为（Normative · 当前真源）

### 2.1 `GET /ge/objectives`

- 一次加载未删 objective + program，**内存**组 `children` / `programs`；禁止递归 sibling 查询。
- `refresh_lifecycle_batch`：TTL≤60s；写路径 invalidate（objective/program create·patch·delete；影响树展示的 project 生命周期写）。
- 冷路径列表类 SQL ≤ **3**（GE-PERF-01）。
- 对外 JSON / 排序语义 bit 兼容。

### 2.2 `GET /ge/projects`

| 形态 | 行为 |
| ---- | ---- |
| **无参** | 全量可见集（PA / 兼容）；树**不用** |
| **`program_ids=`（explode）** | 收窄候选后再 `filter_projects_for_user`（集合预计算 ACL，禁止循环内 `is_subtree_governor`） |
| **`program_id=`** | 单元素别名 |
| **显式空列表** | `200 + []`（勿回落全量） |

前端：仅当展开集含 ≥1 个 `program:`（或项目深链并入）时发 batch。

### 2.3 角标 · `GET /ge/me/project-queue-counts`

- 响应仅 `{ "counts": { project_id: int } }`；禁止明细队列字段。
- 语义 = `submit`+`sign`+`deviation_actions` 中 `ready !== false` 且带 `project_id` 的条数（对齐旧 map）。
- 主树用 count；**不**进树 `isLoading`。
- 画布等仍 `me/queues`；invalidate 必须 queues+count 成对。

### 2.4 展开与深链

| 路由 | 并入 expanded | 树侧 projects |
| ---- | ------------- | ------------- |
| `/execution/programs/:id` | **仅** objective 祖先 + year-group | **否**（详情自带 projects） |
| `/execution/projects/:id` | `program:` + objective 祖先 + year-group | **是**（该 program） |
| 用户点三角展开 program | `program:` | **是** |

存储键：
- **现网（PERF3 前）**：`execution-goals-tree-expanded`（V1）
- **PERF3 后唯一真源**：`execution-goals-tree-expanded.v2`（V2）；见 §4.3。

### 2.5 专项详情

- `GoalProgramDetail`：`getProgram` only；`enabled` 有 id 即请求（不等 objectives loading 门控）。

### 2.6 MeOrg / PA（Phase1 现网 · 摘要）

- portfolio：集合 rollup；GE 查询 ≤5（M≥3）；BFF org 走 `org_claims_cache`。
- PA `goal_objective_tree` 吃同一 `list_objectives`。

### 4.3 P0 · 展开存储升版（Normative · 方案 A）

**问题**：v26.11.27 前点专项写入的 `program:` 仍在旧 sessionStorage，驱动首页膨胀 `program_ids` batch。

**常量（钉死）**

| 名 | 值 |
| -- | -- |
| `STORAGE_KEY_V1` | `execution-goals-tree-expanded`（只读迁移源） |
| `STORAGE_KEY_V2` | `execution-goals-tree-expanded.v2`（唯一读写真源） |

**`loadGoalsTreeExpandedIds()` 算法**

```text
if sessionStorage 无 V2 且无 V1 → { ids: ∅, hasStored: false }
if 有 V2 → 解析数组 → Set（不过滤 program）→ { ids, hasStored: true }
else（仅有 V1）:
  解析 V1 数组
  ids = 保留不以 "program:" 开头的项
  写 V2 ← ids
  删除 V1
  → { ids, hasStored: true }   // 即使迁移后为空集，hasStored=true，避免误走「无存储 → defaultExpanded」分叉时与「已有会话」语义冲突；与现网「有存储则跳过 default」一致
```

**`saveGoalsTreeExpandedIds(ids)`**：只写 **V2**；**禁止**再写 V1。

**与 Layout 的衔接（现网结构 · 勿破坏）**

| 步骤 | 现网行为 | PERF3 约束 |
| ---- | -------- | ---------- |
| mount | `loadGoalsTreeExpandedIds()` → `storedExpandedIds` | 迁移在 **首次 load** 同步完成；禁止在 effect 里晚于首帧 projects fetch 再剔 `program:` |
| `expandedForFetch` | 深链 project 时 merge `program:{deepLinkProgramId}` | 仅影响 fetch 集合；与迁移无关 |
| `selectionAncestorIds` → merge | **仅** `pathname` / `deepLinkProgramId` / objectives 首就绪时 merge 进 stored | **GE-PERF3.1**：禁止 projects batch 刷新触发 merge（否则顶用户 ±） |
| program 路由 | `ancestorGoalsNodeIds` **不含** `program:` | 回归 GE-PERF3-02 |
| toggle 三角 | 可写入 `program:`；专项未拉 projects 前仍显示 ± | 回归 GE-PERF3-03 · **GE-PERF3.1-02** |
**不做**：方案 B（仅首页临时剔）；双键长期并存读写。

### 4.4 P1 · `me/queues` 停轮询（Normative）

**现状**：`useGeQueues(enabled)` → `refetchInterval: 30_000`（恒开）；调用方仅 `ProjectCanvasPage`（`enabled=Boolean(projectId)`）。

**要求**

| 条件 | `refetchInterval` |
| ---- | ----------------- |
| `enabled===false` | 不轮询（现网） |
| `enabled===true` 且 `document.visibilityState === 'visible'` | **30_000** |
| `enabled===true` 且 `hidden` | **`false`**（停） |

- 须订阅 `visibilitychange`（或等价），使 hidden→visible 时 **重新启用** 30s 间隔（不可只在 mount 读一次 visibility）。
- 离开画布路由 → 组件卸载 → 查询停用：现网已满足；**不必**为卸载单独加逻辑，但单测应覆盖「enabled 变 false」。
- **不改**：`queryKey`、`queryFn`、`refetchOnWindowFocus`（可保持 true）、队列 JSON、与 count 的成对 invalidate。
- **不改**：可见时的 30s 数值（本 Phase 不升到 60s）。
